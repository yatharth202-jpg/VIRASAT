# homepage-virasat

VIRASAT is an interactive Indian cultural heritage web platform designed with high-fidelity aesthetics, editorial serif typography, and responsive bento grid layouts.

## Features
- **Hero Section**: Ultra-HD rotating golden hour heritage backgrounds (Konark Sun Temple, Rani Ki Vav stepwell, Brihadisvara temple gateway) with smooth cinematic crossfading.
- **Konark Chakra Motif**: Authentic Konark Sun Temple chariot wheel emblem in scalable gold gradient vector SVG.
- **Explore India Map**: Zoomed-in parchment map with highlighted heritage states.
- **Cultural Categories**: Curated heritage categories (Food, Festivals, Crafts, Monuments, Traditions) with HD photography.
- **Cultural Twins / Find the Connection**: Interactive comparison challenges connecting Indian monuments with world architecture.
- **Virasat Passport**: 3D leather booklet mockup with discovery progress tracking.
- **Elder Wisdom Vault**: Preserved generational artisan stories from master craftsmen.
- **Did You Know**: 4 rotating cultural facts with interactive pagination dots.

## Running Locally
You can run this project with any local HTTP server:
```bash
python -m http.server 8080
```
Then open `http://localhost:8080` in your browser.
