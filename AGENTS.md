# Autonomous Web Development & Design Rules

Whenever the user asks to build, modify, or design any website, page, landing page, component, or UI element:

1. **Automatic High-End Frontend & Visual Design**:
   - Automatically activate `design-taste-frontend`, `high-end-visual-design`, and `stitch-design-taste`.
   - Never generate default, generic AI layouts. Use agency-grade typography, dynamic grid layouts, refined color palettes, responsive design, and smooth micro-interactions.

2. **Automatic UI Reference & Stitch MCP**:
   - Leverage `StitchMCP` design system tools and `generate_image` / `image-to-code` for visual reference creation.

3. **Automatic Planning & Brainstorming**:
   - Apply `brainstorming` and `writing-plans` for any structural or component work before writing code.

4. **Minimalist & Clean Code (`ponytail`)**:
   - Keep HTML/CSS/JS clean, maintainable, and dependency-light. Avoid over-engineering.

5. **Automatic Verification**:
   - Apply `verification-before-completion` to ensure responsive behavior, code correctness, and visual alignment before declaring finished.

6. **Autonomous Execution**:
   - Do all background research, design system creation, image generation, and code editing autonomously without asking the user to manually type commands or invoke plugins.
